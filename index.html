Penjaga Layar (Screen Wake Lock) Aktif

Aplikasi ini secara otomatis meminta browser untuk mencegah layar mati saat tab ini terbuka.

Saran Pengaturan Sistem Operasi (Windows / Laptop):

  • Pengaturan Daya (Power & Sleep): Atur opsi "When plugged in, turn off after" dan "Sleep after" ke posisi Never (Jangan Pernah).
  • Jika Menggunakan Laptop: Atur opsi "When I close the lid" ke Do Nothing (Tidak melakukan apa-apa) agar laptop tetap aktif meski layarnya ditutup.
  • Hemat Daya Browser: Nonaktifkan fitur Memory Saver / Tab Snoozing khusus untuk tab bel sekolah ini di Chrome/Edge agar tab tidak di-suspend oleh browser.
