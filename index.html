💻 Otomatis Aktif Saat PC / Laptop Dinyalakan

✨ Aplikasi Siap Otomatis Aktif Saat Windows Booting!

Agar bel sekolah langsung terbuka dan aktif secara otomatis setiap kali PC/laptop sekolah dihidupkan, ikuti salah satu langkah berikut:

1️⃣ Metode PWA App (Sangat Direkomendasikan)

  1. Klik tombol "Instal Aplikasi Ke PC" di bawah ini atau ikon instal pada address bar browser.
  2. Buka edge://apps atau chrome://apps di browser Anda.
  3. Klik kanan ikon SMP IT NU Asshofiyah Bel Sekolah, lalu centang menu "Jalankan saat Anda login / Komputer Dinyalakan" (Auto-start on OS login).

2️⃣ Metode Folder Windows Startup (shell:startup)

  1. Tekan kombinasi tombol Win + R di keyboard PC/Laptop Anda.
  2. Ketik shell:startup lalu tekan Enter untuk membuka folder Startup Windows.
  3. Salin shortcut browser / PWA aplikasi ini ke dalam folder tersebut. Aplikasi akan otomatis terbuka dan berbunyi setiap kali laptop dihidupkan.
